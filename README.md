# Student Study Tracker

## About the Project

Student Study Tracker is a simple mini project created to learn and demonstrate basic Git and GitHub operations.

## Project Files

- students.txt - Contains student study information.
- tasks.txt - Contains study tasks.
- progress.txt - Tracks project progress.
- git-learning.txt - Contains notes about learning Git.

## Git Commands Practiced

- git status - Check the current state of the repository.
- git add - Stage changes.
- git commit - Save changes in Git history.
- git push - Upload changes to GitHub.

## Objective

The objective of this project is to understand the basic workflow of Git and GitHub through a simple practical project.
